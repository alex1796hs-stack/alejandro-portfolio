## 🇬🇧 English

### Overview

Welcome to the repository for my personal developer portfolio. This web application showcases my background, professional experience, education, technical toolset, and selected software development projects.

Designed with a high-end editorial minimalist dark aesthetic, smooth micro-interactions, responsive video showcases, and a zero-reload internationalization system (English, Dutch, Spanish).

### ✨ Key Features

- **Trilingual Internationalization (i18n):** Native instant language switching between English, Dutch, and Spanish using React Context without page reloads.
- **Editorial Dark Aesthetic:** Custom typography, balanced whitespace, and subtle micro-interactions built with Vanilla CSS and Tailwind CSS.
- **Interactive Project Showcases:** Smooth loop video previews, 16:9 aspect ratios, responsive scaling across desktop, tablet, and mobile devices, along with screenshot galleries.
- **Custom Cursor & Smooth Scrolling:** Enhanced UX with custom cursor tracking and interactive hover states.
- **Fully Responsive Architecture:** Optimized layouts tailored for mobile phones, tablets, laptops, and ultra-wide screens.

### 💻 Getting Started

#### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- `npm` or `pnpm` / `yarn`

#### Installation & Local Execution

1. **Clone the repository:**
   ```bash
   git clone https://github.com/alex1796hs-stack/alejandro-portfolio.git
   cd alejandro-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Run the linter:**
   ```bash
   npm run lint
   ```

### Descripción General

Bienvenido al repositorio de mi portafolio personal como desarrollador de software. Esta aplicación web presenta mi trayectoria, experiencia profesional, formación académica, conjunto de herramientas técnicas y proyectos destacados.

Diseñado con una estética oscura minimalista y editorial de alto nivel, microinteracciones fluidas, presentaciones de vídeo responsivas y un sistema de internacionalización instantáneo sin recarga de página (español, inglés y neerlandés).

### ✨ Características Principales

- **Internacionalización Trilingüe (i18n):** Cambio instantáneo de idioma entre español, inglés y neerlandés mediante React Context sin necesidad de recargar la página.
- **Estética Editorial Oscura:** Tipografía cuidada, espacios equilibrados y microanimaciones elegantes desarrolladas con Vanilla CSS y Tailwind CSS.
- **Muestrario Interactivo de Proyectos:** Vistas previas en vídeo con reproducción en bucle (16:9), escalado responsivo en ordenador, tableta y móvil, junto a galerías de capturas de pantalla.
- **Cursor Personalizado y Scroll Suave:** Experiencia de usuario enriquecida con seguimiento de cursor y estados interactivos al pasar el ratón (*hover*).
- **Diseño Totalmente Responsivo:** Diseños y proporciones adaptados minuciosamente para móviles, tabletas, ordenadores portátiles y pantallas ultra-anchas.
